最初の設定（1回だけ）

  1. GitHub にログインした Chrome で トークン作成ページ を開く
  2. 次のとおり入力して、いちばん下の Generate token を押す
    • Token name: 日記スマホ
    • Expiration: 好きな期間（期限が来たら、ここでもう一度作って貼り直す。選んだ期限の日付を下の「トークンの期限」にも入れておくと、切れる2週間前からこの画面で知らせます）
    • Repository access: Only select repositories → 日記のリポジトリだけを選ぶ
    • Permissions → Repository permissions → Contents を Read and write
  3. 表示されたトークン（github_pat_ で始まる文字列）をコピーして、下に貼る
